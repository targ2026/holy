Como colocar esta página online gratuitamente?

1. GitHub Pages (Recomendado) Cria uma conta no GitHub, cria um repositório público, envia este ficheiro como index.html e ativa o GitHub Pages nas definições.
2. Netlify Drop Acede a Netlify Drop e simplesmente arrasta o ficheiro HTML para lá. Fica no ar instantaneamente.
3. Vercel Cria conta na Vercel e importa o repositório ou envia usando o comando vercel deploy.
